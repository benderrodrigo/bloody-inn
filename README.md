# The Bloody Inn (unofficial web version)

An unofficial fan implementation of *The Bloody Inn* for personal play: 1 to 4 innkeepers,
against AI rivals (Easy, Normal, Hard) or pass and play, with the solo game. Works offline and installs as an app.

**Play:** https://benderrodrigo.github.io/bloody-inn/

The board game is designed by Nicolas Robert and published by Pearl Games. This project is not affiliated with
or endorsed by them; buy the game and read the official rules. All artwork in the app is original (SVG and emoji).
`art.bin` is an encrypted file for the owner's personal copy; it is unreadable and unused without a private key.

Install: open the link in Chrome on Android and choose *Install app* (or *Add to Home screen*)
from the menu; on a laptop use the install icon in the Edge or Chrome address bar.

Saved games and statistics are stored only in your own browser (localStorage).
